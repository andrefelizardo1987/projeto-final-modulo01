# KingDev

Aplicação de página única para comparar habilidades com vagas de exemplo. Desenvolvida com HTML, CSS e JavaScript puro.

## Executar localmente

Abra esta pasta em um servidor estático, como o Live Server, e acesse `index.html` no navegador. O carregamento das vagas e a análise serão conectados nas próximas etapas do desenvolvimento.
